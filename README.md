# ClockInToday No-Interview Jobs Dataset

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24058617.svg)](https://doi.org/10.5281/zenodo.24058617)

Requirements and pay data for **112 US jobs and gig apps you can start without a job interview**, from [ClockInToday](https://clockintoday.com/), a free, independent directory for people who need income fast.

Each row is one platform (delivery and driving, shift work, tasks and labor, pet care, online work, surveys and rewards, plasma and paid studies) with:

- minimum age
- whether there's a criminal background check
- whether a vehicle is needed
- how fast it pays (instant, next day, weekly, and so on)
- reported pay, with the source
- worker type (W-2 employee, contractor, participant)

**Current version:** November 2026. Every listing is rechecked monthly from each company's own pages; see [How we check listings](https://clockintoday.com/how-we-check/).

## Files

- [`clockintoday-no-interview-jobs-data.csv`](clockintoday-no-interview-jobs-data.csv): the full dataset.

## Key findings

The [ClockInToday data report](https://clockintoday.com/report/) summarizes the data with charts, including how many platforms check only ID, which pay within a day, and which accept workers under 18.

## Updates

The live, always-current version is on [ClockInToday.com](https://clockintoday.com/), with a page for every platform and every US state. This repository is updated with each monthly recheck.
